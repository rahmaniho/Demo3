# کارن استودیو — وب‌سایت استودیوی پرتره

وب‌سایت تک‌صفحه‌ای حرفه‌ای فارسی (راست‌چین) برای **کارن استودیو**، استودیوی عکاسی پرترهٔ مستقر در تهران، خیابان ولیعصر.

## ویژگی‌ها

- کاملاً فارسی و راست‌چین (RTL) با فونت وزیرمتن و مارکزی
- ارقام فارسی در سراسر سایت، واحد پول **تومان** و واحدهای متریک (سانتی‌متر، متر مربع)
- تاریخ‌های **شمسی (جلالی)** — از سال ۱۳۹۷ تا ۱۴۰۵ — و نمایش خودکار تاریخ امروز در فوتر
- اطلاعات تماس و آدرس ایرانی: تلفن ثابت تهران، موبایل ایرانی، کد پستی و ایمیل دامنهٔ `.ir`
- صفحهٔ خانه با هیرو موزاییک پویا (Canvas)، شش سرویس، نمونه‌کارها، نرخ‌نامهٔ سه‌سطحی و بخش درباره
- صفحهٔ آرشیو با پالایش دسته‌بندی و نمایشگر تمام‌صفحه (Lightbox)
- پوستهٔ روشن/تاریک، طراحی واکنش‌گرا و رعایت حرکت کمتر (reduced-motion)

## اجرا

```bash
npm install
npm run dev      # سرور توسعه
npm run build    # خروجی نهایی در پوشهٔ dist (تک‌فایل)
npm run preview  # پیش‌نمایش خروجی build
```

## استقرار روی GitHub Pages

استقرار به‌صورت خودکار با GitHub Actions انجام می‌شود (فایل `.github/workflows/deploy.yml`):

- با هر push روی شاخهٔ `main`، پروژه build و روی GitHub Pages منتشر می‌شود
- مسیر پایهٔ Vite نسبی (`base: "./"`) است تا خروجی تک‌فایل در زیرمسیر مخزن به‌درستی بارگذاری شود
- آدرس زنده: **https://rahmaniho.github.io/Demo3/**
